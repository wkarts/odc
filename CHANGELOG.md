## 1.1.0

- ODC Studio PHP completo, executável com PHP built-in server e sem banco de dados;
- ODC Studio HTML/JavaScript puro, offline e sem backend;
- preview local para imagem, vídeo, PDF e texto no Studio HTML/JS;

- novos artefatos `odc-studio-php-*` e `odc-studio-html-js-*` no GitHub Release;
- CI dedicada para validar os Studios e smoke test do Studio PHP;
- documentação e PR ready package.
