# Quickstart

## PHP

```bash
php php-laravel/bin/odc info test-vectors/hello.odc
php php-laravel/bin/odc verify test-vectors/compressible.odc
```

## Node.js

```bash
node nodejs/bin/odc.js info test-vectors/hello.odc
```

## Go

```bash
cd golang
go run ./cmd/odc info ../test-vectors/hello.odc
```

## Shell

```bash
shell/odc.sh info test-vectors/hello.odc
```

## PowerShell/Windows

Execute `bin/windows-x64/ODC-Studio.exe` ou abra `powershell/ODC-Studio.ps1`.
